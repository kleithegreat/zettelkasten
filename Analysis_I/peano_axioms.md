# Peano Axioms
**Definition**: The *Peano axioms* are a set of axioms for the [[natural_number|natural numbers]], typically stated as follows:
1. There is a distinguished natural number called $0$.
2. Every natural number has a unique successor, denoted $S(n)$.
3. $0$ is not the successor of any natural number.
4. Different natural numbers have different successors: if $S(n) = S(m)$, then $n = m$.
5. (Principle of Mathematical Induction) Let $P(n)$ be any property pertaining to a natural number $n$. Suppose that $P(0)$ is true, and that for every natural number $k$, if $P(k)$ is true, then $P(S(k))$ is also true. Then $P(n)$ is true for all natural numbers $n$.
